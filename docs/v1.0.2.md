Los tres archivos son copias exactas de los adjuntos aprobados. Miden 768 × 355, igual que el Canvas: no se recortan ni deforman. Se cargan una sola vez mediante el sistema de recursos existente y se reutilizan. Cada ruta incluye una versión derivada del SHA-256 del PNG.

`battleBackdrop()` dibuja el fondo del encuentro antes que enemigos, héroes e indicadores, sin suavizado y restaurando el estado de Canvas. Si falla una imagen, se muestra el escenario original de ese encuentro y el aviso de carga; el combate sigue disponible. No hay nuevos bucles ni esperas de combate.

La habilidad de Óscar se renombra exactamente a **Te llevo al Clot y te enseño los pajaros**. Se modifica solo su dato de habilidad; el diálogo/modal, el botón y el mensaje de uso consumen ese dato. Se conserva la frase de presentación «Yo juego eminencias, pero que no están chetas», ya que es su diálogo y no el nombre de habilidad. El coste, daño, efectos y reglas permanecen idénticos.

## Pruebas realizadas

- Comparación de Óscar contra el combate del commit base: mismo estado, coste de 8 PM, daño y resultado; solo difiere el texto visible.
- Los tres fondos se comparan píxel por píxel con sus imágenes, comprobando orden de dibujo, ausencia de suavizado, tamaño y una única solicitud por recurso.
- Nombre nuevo comprobado en modal, botón y mensaje de habilidad.
- Simulación de fallo de los tres fondos: aviso, escenarios originales y combate funcional.
- Regresión de 15 protagonistas, diálogos y retratos, Pere, reclutamiento, límites y botón de mazmorra.
- 210 interacciones, 2730 equipos ordenados, 45 dibujos de héroes; animaciones con 90 variantes de máscara y 270 dibujos, inversión, anclajes y estados.
- Tres encuentros, ambas transiciones de fase II, habilidades, defensa, pociones, derrota/reintento y cofre. Recorrido automatizado con PV/PM normales usando David, Carlos y Jordux, con azar determinista.
- Rutas en raíz y bajo `/amigo-invisible-rpg/`, sin rutas rotas ni excepciones JavaScript en carga normal.
- Chromium escritorio y móvil táctil emulado DPR2. Revisión visual de capturas de los tres escenarios, con héroes, enemigos, nombres e indicadores visibles.

Limitaciones: no se probaron teléfonos físicos, Safari ni Firefox. La finalización se automatiza, no corresponde a una partida manual completa. La publicación real queda a cargo del usuario.

### Ejecutar las pruebas

Desde un clon con historial Git, Node.js y Playwright disponibles:

```sh
node tests/animations.cjs
node tests/heroes.cjs
node tests/regression.cjs
node tests/adventurers.cjs
node tests/heroes.cjs --browser
node tests/tavern.cjs
node tests/backgrounds.cjs
```

Las dos primeras órdenes verifican lógica; las restantes ejecutan comprobaciones en navegador con servidor local temporal. Se requiere Chromium de Playwright (`npx playwright install chromium`) o `BROWSER_PATH` indicando un ejecutable disponible. Estas herramientas no se añaden al juego publicado.
